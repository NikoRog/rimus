About Rimus

Rimus is a fast party game about saying rhymes out loud, keeping flow, and reacting quickly.

How to Play

  1. Get a sentence with a highlighted word.
  2. Say a line that rhymes with the word.
  3. Tap the card when the group accepts it.

Modes: Free Play, Survival, and Rivals.

Current Version

v0.6 Beta focuses on functionality, modes, subject unlocks, offline prompt generation, Firebase Analytics consent, and debug tools.

Data & Privacy

Firebase Analytics only runs after consent. Rimus uses anonymous gameplay events only. No account is required, and no personal data is intentionally collected.

Users can disable analytics in Settings. Events may include mode, subject, rounds, unlock order, button use, and device/browser information provided by analytics.

Firebase web config is public by design. No server keys or paid API keys belong in frontend code. Firestore or Storage must have security rules before use.

Feedback

Open beta feedback is welcome: confusing prompts, repeated words, broken flows, balance issues, and mobile problems are the most useful reports.
